# Learning C++ & Vulkan

## About This Project

This repository documents my personal journey of learning modern C++ and Vulkan, with the long-term goal of building my own graphics engine from scratch.

The project is driven by curiosity and a desire to deepen my understanding of low-level programming, computer graphics, and software architecture. It is a self-directed learning initiative, independent of any academic coursework, with no fixed deadlines.

## Learning Objectives

The learning process is divided into three main areas:

### 1. Modern C++

Build a strong foundation in C++20, covering everything from fundamental language concepts to more advanced topics, including:

- Memory management, pointers, references, and object lifetimes
- Object-oriented programming, RAII, and ownership
- STL containers, algorithms, templates, and move semantics
- Concurrency, debugging, testing, and build systems
- Low-level programming, memory layout, and performance

### 2. Vulkan & Computer Graphics

Explore graphics programming through Vulkan, focusing on GPU architecture, rendering pipelines, shaders, memory management, synchronization, and resource handling.

### 3. Custom Graphics Engine

Apply the acquired knowledge to gradually design and develop a custom graphics engine, focusing on maintainable architecture, resource management, and rendering systems.

## Learning Approach

The project follows a **concept-based, mastery-oriented approach**, rather than a fixed schedule.

Each topic is explored through theoretical explanations, practical exercises, debugging challenges, and knowledge assessments. Related concepts are combined into larger exercises and progressively more complex projects.

The emphasis is on understanding **how and why things work**, rather than simply following tutorials or producing working code.

## Development Environment

- **Language:** C++20
- **IDE:** Visual Studio 2022
- **Compiler:** MSVC
- **Build System:** CMake
- **Version Control:** Git
- **Platform:** Windows 11

## Repository Structure

- `cpp/` — Individual C++ concepts, examples, and exercises
- `integration/` — Exercises combining multiple concepts
- `projects/` — Larger applications and experimental components
- `notes/` — Additional technical notes
- `vulkan/` — Vulkan experiments and graphics development

The repository will evolve organically as new concepts are introduced and explored.

---

**The ultimate goal is not simply to build an engine, but to understand the systems, abstractions, and decisions behind it.**
